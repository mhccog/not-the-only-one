Quiet discovery

How this works

Type a problem and this page asks open, public sources who has worked on it in the last twelve months: research papers on OpenAlex (which includes arXiv preprints), new repositories on GitHub, and discussions on Hacker News. Quiet discovery also uses arXiv directly, refreshed weekly.

It then groups efforts that describe nearly the same thing, using plain word overlap in your browser (no AI service), and keeps only groups made by independent people: no shared authors, no shared owner, close together in time.

Every dot is a real record and links to it. Places come from the authors' listed institutions, or from the public location on a GitHub profile; when only a country is known the dot sits at the country's centre and says so. Dates are when work was published, created or posted, not when it began. Nothing is invented, and if a source is unavailable the page says so.

Introductions are coming later, with consent. Today this only shows public work. It contacts no one, needs no login and stores nothing about you.
